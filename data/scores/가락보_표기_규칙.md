# 가락보 표(hwp/pdf) 읽는 규칙

선생님이 준 실제 가락보(마동초 사물놀이1.pdf)를 JSON으로 옮길 때 지켜야 하는 규칙. 표의 원래 레이아웃만 보고는 헷갈리기 쉬운 부분이라 별도로 정리한다.

## 1. 암기용 단어(짜장면, 스파게티 등)는 표시 전용이다
표 안에 리듬 줄과 나란히 "짜장면", "스파게티", "정말맛있어요" 같은 단어가 적혀 있는 경우가 있다. 이건 학생이 리듬을 외우기 쉽도록 같은 박자 위치에 붙여둔 암기용 단어일 뿐, 실제 타격이나 강약과는 무관하다.
- score_schema.py의 Cell에 `mnemonic: str | None = None` 필드로 추가해서, 해당 박자에 단어가 있으면 채우고 없으면 비워둔다.
- `strike_count`나 정렬(align) 로직에는 전혀 영향을 주지 않는다 — 웹 플레이어에서 화면 표시용으로만 쓴다.

## 2. 표에 한 줄만 있으면 "전 악기가 같이 친다"는 뜻일 수 있다
보통 한 구간은 꽹과리/장구/북/징 4줄로 각자의 리듬이 따로 적혀 있다. 그런데 가끔 줄이 하나만 있는 구간이 있는데, 이는 표기를 아낀 것일 뿐 실제로는 그 구간에서 모든 악기가 (또는 명시된 일부 악기가) 똑같은 리듬을 동시에 친다는 뜻이다.
- 실제 인코딩(4개 악기 JSON 파일 각각 채워 넣기) 시, 이런 구간을 만나면 같은 셀 내용을 해당하는 모든 악기 JSON에 동일하게 복사해 넣는다.
- **확인 필요**: "타령장단" 표의 "털기읏 갱 갱..." 구간(2줄 반복 후 "궁 따 따"가 이어지는 부분)이 정확히 어떤 의미인지 아직 불확실 — 선생님 확인 후 이 문서에 예시로 추가할 것.

## 3. 짝쇠 / "~변형" 표는 장구만 바뀌는 경우가 많다
- **짝쇠(상쇠·부쇠)**: 이 표는 꽹과리 연주자 두 명(상쇠/부쇠)이 주고받는 변형 가락 연습이다. 장구/북/징의 독립적인 리듬은 표에 없다 — 이 구간은 꽹과리 파트로만 인코딩한다.
- **"~변형가락", "~변형장단"**: 이름이 붙은 세트 안에서 "기본가락"과 "변형가락"이 나란히 나올 때, 보통 장구의 리듬만 기본에서 변형으로 바뀌고 꽹과리/북/징은 기본가락과 동일하게 유지된다.
  - 예: "휘모리 기본 가락"이 두 페이지(21, 25)에 걸쳐 나오는데, 꽹과리(갱-개갱)·북(둥-두)·징 줄은 두 버전이 거의 동일하고, 장구 줄만 다르다 (21페이지: 궁-기따-궁-다-쿵-기따-쿵-다 / 25페이지: 덩-덩-쿵-따-쿵으로 더 단순화).
  - 인코딩할 때 "변형" 버전을 만들 때는 장구 JSON만 새로 작성하고, 꽹과리/북/징 JSON은 기본가락 버전을 그대로 재사용한다 (파일을 복사해서 그대로 쓰거나, 같은 내용을 다시 채워 넣는다 — 상속 메커니즘 같은 건 만들지 않는다, 패턴 개수가 많지 않아 중복 작성이 더 단순함).
