# 육채 녹음 반영 (2026-09-22)

사용자가 제공한 `육채.m4a`의 타격 시점·주파수 대역별 상승량을 분석하고,
사용자가 확인해 준 네 가지 주고받기 박자와 마지막 구간 설명을 반영했다.
원본 녹음은 저장소에 포함하지 않는다. 악기 분리 음원을 만들지는 않았다.

## 구간과 속도

| 재생 항목 | 반복 | 기본 BPM | 분석 기준 |

마지막 구간의 8회 템플릿 적합에서는 약 56.91~70.23초, 시작 299 BPM,
회당 +19 BPM이 산출되어 시작값을 300으로 반올림했다. 사용자가 지정한
58초 경계와 정확히 일치하는 분할은 아니며, 자연 연주의 흔들림을 평균화한
근사값이다. 재생 BPM은 300, 319, 338, 357, 376, 395, 414, 433이다.
58초부터 별도의 8회가 정확히 들어간다고 단정하지 않는다.

## 주고받기

0부터 센 한 구절의 타격 칸:

1. 덩 덩 더덩 더덩: 0, 2, 4, 5, 7, 8
2. 더더덩 더덩 더덩: 0, 1, 2, 4, 5, 7, 8
3. 덩 더덩 덩 더덩: 0, 2, 3, 5, 7, 8
4. 더더더더더더더더덩덩: 0~9 전체

꽹과리 선창은 갱으로 표기한다. 사용자 지시에 따라 응답 장구는 같은
위치의 덩, 북은 둥으로 표기한다. 1~4형 뒤 다시 1~4형 순서로 연주한다.
약하게 검출된 45.59초, 53.96초, 54.845초 타격도 해당 형태와 대조했다.
징은 기존 한 구절을 각 주고받기 쌍의 시작에 유지한다.

마지막 다 같이 구간의 장구는 `덩 / 쉼 / 덩 / 쉼 / 더 / 덩 / 쉼 / 더 / 덩 / 쉼`.
북은 덩인 0, 2, 5, 8칸에만 둥을 친다. 기존의 별도 종료 구절을 뒤에 덧붙이지 않는다.

기존 저장 목록의 `yukchae` 항목은 새 네 항목으로 순서대로 확장한다.
다른 가락 데이터, 칠채 변경, BPM 및 관리자 편집 기능은 유지한다.
