# 구음 목소리 재생

`gakbo-player.html`을 열고 **재생**을 누릅니다. 별도 서버 없이 파일로 열 수 있습니다. `voice-samples.js`는 HTML과 같은 폴더에 있어야 합니다.

- **구음**: 남성 TTS로 미리 생성한 구음 파일을 재생합니다. 실시간 TTS 요청은 없습니다.
- **악기 소리 (준비 중)**: 실제 타악기 녹음은 아직 없으므로 선택할 수 없습니다. 구음 파일을 실제 악기 음원으로 대체 재생하지 않습니다.
- **표시·재생할 악기** 체크박스 하나로 표시와 소리를 함께 선택합니다. 장구만 체크하면 장구 구음만 읽으며, 구음 줄을 체크하면 그 줄의 글자를 읽습니다.
- 한 칸 = 1박인 기존 BPM 기준을 유지합니다. 음높이와 재생 속도는 고정하고 시작 간격만 변경합니다.
- 갠지/기따만 한 음원입니다. 기덩 등 다른 여러 글자는 칸 안에서 같은 간격으로 나눠 읽습니다.
- 원본 구음을 칸 길이에 맞춰 자르지 않고 끝까지 읽습니다. 매우 빠른 BPM에서는 발음이 겹칠 수 있습니다.
- 쉼에는 새 구음을 읽지 않습니다. 화면 전환만으로 자동 정지하지 않습니다.
- 칠채 기본가락 후렴의 암기용 글자(짜장면정말맛있어요)를 구음 줄로 분리하고, 꽹과리 줄은 같은 타격 위치의 갱으로 구분했습니다. 박자 위치와 쉼은 유지했습니다.

## 음원

`audio/voice/`에는 개별 MP3, `voice-samples.js`에는 오프라인 로딩용 base64 사본이 있습니다. 사용자가 확인한 개별 음원을 재사용하고, 나머지 글자만 동일한 한국어 남성 InJoonNeural / rate -10% / pitch +0Hz 설정으로 추가했습니다. 첫 자음 보존을 위해 무음 제거, 재인코딩, 시작 페이드 없이 원본을 그대로 사용합니다. 음높이 평탄화는 하지 않았습니다. 추가 생성 글자는 별도 발음 검수가 필요할 수 있습니다.

## 실제 악기 소리 확장

`soundBanks.voice`와 `soundBanks.instrument`는 구분되어 있습니다. 실제 악기 모드는 향후 **악기 키 + 연주 구음**별로 음원을 등록하고, 별도 디코딩·재생 분기를 구현한 다음 버튼을 활성화해야 합니다. 현재 instrument 맵을 채우는 것만으로 활성화되는 완성 기능은 아닙니다. 구음 줄은 실제 악기 매핑 대상이 아닙니다.

## 확인한 동작

Microsoft Edge 자동화에서 전체 음원 디코딩 및 누락 검사, 90 BPM 예약 간격, playbackRate=1, 정지 후 예약 중단, 위치 이동, 음소거 제어, 800 BPM 반복 구간 전환, 상쇠/부쇠 표시, JavaScript 오류 없음 확인.

수정 후 장구 단독 선택으로 7.5초 동안 6개 장구 구음만 예약되며 첫 타격 이후에도 실제 오디오 출력이 지속되는 것을 분석기로 확인했습니다. 구음 211칸의 음원 누락 없음, 구음만 선택한 경우 짜/장/면 음원만 재생됨을 확인했습니다.
